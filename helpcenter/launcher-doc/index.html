网页启动台

所有站点的统一入口：一个搜索框直达全部站点，图标取各站实时 favicon，顶部时钟自带月历。

能做什么

  • 搜索直达输入站点名或关键词，直接跳到对应站点。
  • 分类筛选按类别过滤站点，缩小范围更快找到。
  • 实时站点图标每个站点的图标就是该站当前的 favicon；远程加载失败时自动回退本地图标，再回退到 emoji。
  • 日历时钟顶部时钟悬停或点击即可弹出月历面板，含农历与节日标注。
  • 深浅主题一键切换浅色与深色，跟随你的偏好。
  • 小蓝页单点登录在启动台登录一次，各站身份互通。

怎么登录

网页启动台与小蓝页共用一套账户：用小蓝页账户登录，身份在各站之间互通。

  • 小蓝页账户登录点右上角「登录」，邮箱验证码或 GitHub 都行。
  • 身份互通启动台登录后，书栈、茶馆、片屿等站点自动识别同一身份。
  • 创作者功能自动开放书栈、茶馆等需要创作者角色的功能，登录后自动获得相应角色。

主要功能速查

  • 搜索框搜站点名或关键词直达。
  • 分类筛选按类别缩小范围。
  • 站点图标实时 favicon，失败回退本地图标再回退 emoji。
  • 时钟与月历悬停或点击弹出月历，含农历与节日。
  • 主题切换浅色 / 深色自由切换。
  • 单点登录小蓝页账户，身份互通。

常见问题

某个站点图标不显示怎么办？
图标有三级回退：先取该站实时 favicon，远程加载失败就用本地图标，再失败就退到 emoji，所以通常总能认出来。
月历怎么打开？
把鼠标悬停在顶部时钟上，或直接点击它，月历面板就会弹出。
月历里有什么？
公历日期之外，还标注了农历和节日。
启动台要单独注册吗？
不用。用小蓝页账户登录即可，身份在各站之间互通。
搜索没找到想要的站点怎么办？
搜索按站点名称匹配；换个关键词，或用分类筛选浏览整站列表。
