片屿 Pianyu

一个独立的视频站：上新、看片、聊屿论，也可以把作品发到自己的创作岛。

能做什么

  • 上新在 admin.html 上新，把新的内容放上片屿。
  • 看片在 watch.html 播放内容，进度与清晰度都在这里调。
  • 屿论与定点屿论边看边聊；把某条屿论钉在特定时间点，它就会在那一刻出现。
  • 岛图在 map.html 用地图的方式浏览片库。
  • 创作岛在 creator.html 发布自己的作品。
  • 收藏夹与设置收藏喜欢的片子，在设置页调整个人偏好。

怎么登录

片屿与小蓝页共用一套账户：用小蓝页账户登录，身份在各站之间互通。

  • 用小蓝页账户登录邮箱验证码或 GitHub 登录都行。
  • 登录后自动获得创作者角色上新、创作岛发布等创作者功能，登录后自动开放。
  • 身份互通收藏夹等个人数据跟着你的账号走，在各站之间互通。

主要功能速查

  • admin.html上新，把新内容放上片屿。
  • watch.html播放与观看页。
  • 屿论 / 定点屿论边看边聊，或把评论钉在某一刻。
  • map.html用地图浏览片库。
  • creator.html发布自己的作品。
  • 收藏夹 / 设置页收藏与管理个人偏好。

站点地址：打开片屿

常见问题

屿论和定点屿论有什么区别？
普通屿论跟着播放进度往下滚；定点屿论被钉在某个时间点，播到那一刻必定出现。
怎么发布自己的作品？
登录后到创作岛 creator.html 发布即可。
上新和创作岛有什么区别？
上新 admin.html 用于放上新内容；创作岛 creator.html 是放你自己作品的地方。
收藏在哪里看？
登录后进入收藏夹；因为身份在各站之间互通，换设备登录也是同一份收藏。
看片需要额外安装什么吗？
不需要，浏览器直接打开网页即可播放。
