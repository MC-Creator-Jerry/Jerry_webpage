CleanOpt

Windows 系统清理与内存优化小工具，PowerShell WinForms 界面，免安装、可静默后台运行。

能做什么

  • 磁盘垃圾清理清掉临时文件、系统缓存和回收站冗余，安全释放磁盘空间。
  • 内存优化释放被占用的内存，提升系统响应速度，减少卡顿。
  • 系统工具面板把常用的系统维护入口收在同一处。
  • 后台静默运行常驻后台、不弹窗不打扰，按需自动维护系统。
  • 定时任务随附 daily_run.ps1，可交给 Windows 任务计划程序每天执行。
  • 三段式版本号版本号形如 [年.月日.时分]，例如 2026.0831.1813，一眼看清是哪个构建。

怎么登录

CleanOpt 是本地工具，不联网、不需要登录；安装包与更新日志发布在小蓝页的 /products/cleanopt/ 。

  • 不需要登录下载解压后直接运行，所有清理动作都在你本机完成。
  • 到小蓝页取安装包安装包与历史版本都在 /products/cleanopt/ 。
  • 需要跨站身份时再登录小蓝页用邮箱验证码或 GitHub 登录，身份在各站之间互通。

提示：CleanOpt 不写注册表、不建服务、不做静默提权，清理前会先列出将要处理的条目。

主要功能速查

  • 清理先列出项目，确认后才执行。
  • 内存手动释放被占用的内存。
  • 工具常用系统维护入口集中一处。
  • 设置开关自动维护、后台静默与开机自启。
  • daily_run.ps1给任务计划程序做每日定时调用。
  • /products/cleanopt/安装包与版本记录。

常见问题

会误删我的文件吗？
不会。它只清理明确安全的系统冗余——临时文件、系统与浏览器缓存、回收站残留、无效缩略图；执行前会先列出清单供你确认，文档、图片、下载和桌面都不动。
需要管理员权限吗？
日常使用普通用户即可；清理系统级目录时部分条目会提示你以管理员身份再运行一次，它不会偷偷提权。
怎么设置每天自动清理？
用随包的 daily_run.ps1，在 Windows 任务计划程序里新建一个每日任务指向它即可。
版本号怎么读？
三段制 [年.月日.时分]，例如 2026.0831.1813；安装包下载页会标出当前版本。
会不会留一堆残留？
不会。免安装便携版，解压即用，不写注册表、不建服务，删掉文件夹就等于卸载干净。
