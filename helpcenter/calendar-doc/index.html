Jerry 日历

简洁的在线日历：月视图一目了然，点日期记日程，节假日自动标记，红色主题醒目。

能做什么

  • 月视图整月日期一屏看完，今天用红圈高亮，周末标红。
  • 日程管理点任意日期添加日程：标题、时间、六色标签，随时删除。
  • 节假日标记元旦、劳动节、国庆等公历节日自动标注在日期上。
  • 数据存本地日程保存在你的浏览器里，刷新不丢，无需注册。
  • 深浅主题右上角一键切换浅色与深色，也可以跟随系统。
  • 全设备适配手机上日程面板自动变成底部抽屉，窄屏也不挤。

主要功能速查

  • 切月点标题两侧箭头，或用键盘 ← / →；按 T 回到今天。
  • 记日程点日期 → 填标题和时间 → 选颜色 → 添加。
  • 删日程日程条目右侧的删除按钮一键移除。
  • 主题切换右上角月亮按钮，浅色 / 深色自由切换。

常见问题

日程会同步到其他设备吗？
目前日程保存在本机浏览器（localStorage），换设备或清浏览器数据后不会跟随。跨设备同步在规划中，后续会接入小蓝页账户。
要注册账号吗？
不用。打开就能用，记的日程存在你自己的浏览器里。
日历是红色主题？
对，Jerry 日历以红色为主题色：今天的高亮、按钮和图标都是红色系，日期上的彩色小方块是日程标签的示例色。
有农历和节气吗？
目前标注公历节日；农历与节气标注在规划中。
