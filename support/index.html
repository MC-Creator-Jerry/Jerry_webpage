赞助之后怎么解锁

  1. 在第三方平台完成支付。付款时记得在「订单留言」里写上你的小蓝页用户名（也就是你用 GitHub 登录后的那个名字，比如 MC-Creator-Jerry）——这样付款后权益会自动到账，不用你再做任何事。
  2. 回到本站登录（用 GitHub 登录），打开兑换页。
  3. 把兑换码贴进去，点「兑换」——权益当场生效，不需要等我人工处理。

留了用户名 → 自动到账，下面两步可以跳过；没留 → 爱发电发的兑换码贴进兑换页，一样能解锁。两种方式效果完全相同。

每一档有效期 31 天。续费之后平台会再发一条新的码，回兑换页再贴一次即可自动顺延。

常见问题

支持是订阅还是一次性？
两种都行。一次性打赏随时欢迎；订阅档位按月计费，可以随时停。
能退款吗？
数字内容与软件授权一经发放，原则上不支持退款；如果确实是重复付款或权益没到账，走第三方平台原路退回，或者把它转成对应月份的权益。
能开发票吗？
目前通过第三方平台收款，发票以平台提供的能力为准（平台能开就走平台）。需要正式发票的话，请在付款前先到留言页问一下，我确认可行再收你的钱。
我的隐私会被怎么处理？
站内只保留运行所需的最少数据，具体见隐私政策。付款信息由第三方平台处理，我这边看不到你的支付凭证细节。
不想花钱，还能帮上忙吗？
当然可以，而且同样重要：把你的使用体验和 Bug 发到留言页、把 CleanOpt 推荐给需要的人、在帖子里认真评论——这些都直接让项目变得更好。
