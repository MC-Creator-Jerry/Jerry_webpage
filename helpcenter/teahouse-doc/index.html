茶馆 JerryTeahouse

一间独立的论坛茶室：慢慢泡茶、慢慢写字。小蓝页单点登录，进门就能发帖。

能做什么

  • 发帖在 /new/ 写新帖：提问、分享、随手记。
  • 帖子中心/posts/ 汇总全部帖子，按时间浏览。
  • @提及与转发在正文里 @ 某人，或把帖子转发出去。
  • 评论与回复对帖子下评论，并在评论下继续回复。
  • 收藏夹与关注收藏帖子、关注感兴趣的成员。
  • 通知与打赏站内通知实时提醒回复与@提及；调度券可用于给喜欢的帖子打赏。
  • 档案页与管理台/profile/?user=xxx 查看他人档案；管理员有专门的管理台。

怎么登录

茶馆与小蓝页共用一套账户：用小蓝页账户登录，身份在各站之间互通。

  • 用小蓝页账户登录邮箱验证码或 GitHub 登录都行。
  • 登录后自动获得创作者角色发帖、评论、转发、收藏、打赏等创建者功能，登录后自动开放。
  • 身份互通在茶馆登录，其它站点自动识别同一身份，无需重复注册。

提示：调度券在小蓝页每日签到获得，可以直接在茶馆给喜欢的帖子打赏。

主要功能速查

  • /new/写新帖。
  • /posts/浏览全部帖子。
  • @提及 / 转发点名某人或把帖子分享出去。
  • 评论与回复帖子下评论并层层回复。
  • 收藏夹 / 关注收藏帖子、关注成员。
  • /profile/?user=xxx查看他人的档案页。

站点地址：打开茶馆

常见问题

怎么查看别人的主页？
打开 /profile/?user=用户名，把用户名换成对方即可。
调度券怎么用？
在帖子下用调度券打赏作者；调度券来自小蓝页每日签到。
@提及对方会收到什么？
对方会在站内通知里看到提醒，点进去就能回到那条帖子。
在茶馆需要再注册一次吗？
不需要。用小蓝页账户登录即可，身份在各站之间互通。
管理员有什么不同？
管理员登录后会多出管理台入口，可以处理站内的帖子与内容。
