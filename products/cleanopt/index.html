系统要求

  • 操作系统Windows 10 / 11（64 位）。Windows 7/8 未测试，不保证可用。
  • 运行环境PowerShell 5.1 与 .NET Framework 4.5+，均为 Windows 10/11 内置，无需额外安装。
  • 权限普通用户即可运行；清理系统级目录时部分项会提示用管理员身份运行，不会悄悄提权。
  • 磁盘空间解压后约 1 MB；运行时零写入系统盘，不写注册表、不建服务。
  • 内存占用后台常驻约数十 MB 级（视系统而定），可在设置里关闭自动维护改为手动，进一步降低占用。

安装与使用

  1. 1
    下载：在本页点「下载 CleanOpt」，得到一个 .zip 压缩包。
  2. 2
    解压：右键压缩包 →「全部解压缩」到任意文件夹（桌面、D 盘都行）。不要放在 C 盘 Windows 系统目录里。
  3. 3
    运行：双击 CleanOpt.ps1（或打包好的 .exe）即可启动，无需安装、不写注册表。
    首次运行若被 SmartScreen 拦截：点「更多信息」→「仍要运行」。这是未签名脚本的正常提示，文件来自本页即可信。
  4. 4
    清理：在「清理」页点「立即清理」，会先列出将要清理的项，确认后再执行；也可在「设置」里开启自动维护，让它每天定时后台清理。

提示：PowerShell 脚本默认可能被系统禁止运行。若双击无反应，用管理员 PowerShell 执行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 后再双击即可。

    常见问题

    会不会误删我的文件？
    不会。CleanOpt 只清理明确安全的系统冗余——临时文件、浏览器/系统缓存、回收站残留、无效缩略图等；不碰你的文档、图片、下载、桌面等个人文件。执行前还会先列出将要清理的项，确认后才会动手。任何清理工具都有极小风险，重要数据请先备份。
    占多少内存 / 资源？
    很轻量。后台常驻约数十 MB 内存（视系统而定），CPU 只在清理那一刻短暂占用，平时几乎为零。不需要时可到「设置」关闭自动维护，改为手动点「立即清理」，占用降到最低。
    会开机自启吗？
    默认不会强制开机自启。首次运行只是普通启动，不会偷偷塞进开机启动项。想让它开机自动后台运行，可在「设置」打开「开机自启」（或手动把快捷方式放进「启动」文件夹）。所有开关都靠你主动点，没有隐藏行为。
