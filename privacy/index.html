隐私政策

最后更新：2026-09-18
小蓝页是一个个人站点。我只收集让站点能正常运转所必需的数据，不做广告画像，不把数据卖给任何人。下面逐项说明。

一、收集哪些数据

类别具体内容什么时候产生
账号信息 GitHub 用户名、显示名、头像地址、用户 ID 你使用 GitHub 登录时
你的自定义资料 昵称、简介、自定义头像、主页背景、字体与主题偏好 你在设置页保存时
你发布的内容 帖子、评论、留言、私信、群组内容及附件；发布时间 你主动提交时
联系表单 姓名、邮箱、反馈分类、来源页面、IP 地址、提交时间、正文 你提交留言或建议时
技术性数据 访问计数、首次访问时间、用于限流的请求标识 你浏览页面或频繁请求接口时
封禁记录 被处罚的用户名与到期时间 仅在你违反站规被处理时

二、为什么收集

  • 登录与身份识别：知道「这条帖子是谁发的」。
  • 显示与个性化：头像、昵称、主题与字体偏好。
  • 回复你：联系表单收集的邮箱只用于回复你的问题，以及给你发一封自动确认信。
  • 安全与防滥用：限流、防刷、处理举报与封禁。
  • 了解大致流量：访问计数用于知道站点是否有在用。

不会做的事：不投放第三方广告画像、不把数据出售或出租给第三方、不用于与上述无关的用途。

三、存在哪里、留多久

  • 站点部署在 Cloudflare Pages，数据存放在 Cloudflare 的键值存储（KV）中，由 Cloudflare 提供基础设施安全。
  • 帖子、评论等内容会一直保留，直到你删除或注销账号。
  • 联系表单记录保留约 1 年。
  • 限流用的计数器只在短时间内有效，过期自动清除。

四、Cookie 与浏览器本地存储

  • 登录后会写入若干 Cookie（如 gh_user、gh_uid；访问令牌为 HttpOnly），用于识别你的登录状态。退出登录或注销账号会清除。
  • 浏览器本地存储（localStorage）保存你的语言、主题、字号等偏好，只存在你自己的设备上。
  • 本站不使用广告 Cookie 或跨站追踪 Cookie。

五、第三方服务

服务用途
Cloudflare网站托管、数据存储、访问计数
GitHub第三方登录；头像图片可能来自 GitHub
网易邮箱（163）向你发送自动回复与通知邮件
第三方收款平台若你通过支持页赞助，支付信息由该平台处理，本站不接触你的支付凭据

六、你的权利

  • 查看与更正：在「设置」与「个人主页」里可以修改你的昵称、简介、头像与背景。
  • 删除：你可以自行删除自己发布的帖子与评论。
  • 注销账号：在设置页可以注销，会清除你的资料、偏好与通知，并删除你发布的帖子。
  • 其他请求：想导出或补删数据，可通过留言页或邮箱联系我。

七、未成年人

本站不是面向儿童设计的服务。若你未满 14 周岁，请在监护人同意并指导下使用。

八、政策变更

如果这份政策有实质性修改，我会更新本页顶部的日期。继续使用本站即视为接受更新后的版本。

九、联系方式

任何隐私相关的疑问或请求，都可以通过留言页或邮箱 jerryprdservice@163.com 联系我。

⚠️ 这份政策是按站点当前的真实实现写的草稿。
