噪音警报器 Noise Alarm

一个纯静态的浏览器工具：用麦克风实时测噪音，超过你设定的分贝阈值就报警。

能做什么

  • 麦克风实时测噪用 getUserMedia 取音频流，算 RMS 转成 dBFS 实时显示。
  • 分贝阈值设定自己定一条线，超过才算超标。
  • 超阈值三态机ARMED 待命、ALARMING 报警中、MUTED 静默，状态一目了然。
  • 迟滞与持续判定5dB 迟滞加持续 800ms 判定，避免声音忽高忽低时反复误报。
  • 四种报警方式红闪、蜂鸣、振动、桌面通知同时可用，眼睛耳朵都不耽误。
  • 纯静态页面打开网页就能用，不需要安装任何东西。

怎么登录

噪音警报器是纯静态工具，不收集数据、不需要登录，麦克风信号只在本机处理。

  • 无需登录打开页面、授权麦克风即可开始测噪。
  • 全部在本机处理音频流不出浏览器，不上传、不留存。
  • 需要跨站身份时再登录小蓝页用邮箱验证码或 GitHub 登录，身份在各站之间互通。

提示：浏览器会先弹出麦克风授权请求，被拒绝后请在地址栏的权限图标里重新允许。

主要功能速查

  • 实时读数RMS → dBFS 实时显示。
  • 阈值设定自己定报警线。
  • ARMED待命，随时监听。
  • ALARMING / MUTED报警中与静默两种状态。
  • 5dB + 800ms迟滞与持续判定，抑制误报。
  • 红闪 / 蜂鸣 / 振动 / 通知四种报警方式。

常见问题

需要安装插件吗？
不需要，纯静态页面，浏览器打开即用；只有麦克风授权这一步需要你点一下同意。
麦克风会被上传吗？
不会。音频流通过 getUserMedia 取得后只在浏览器里计算 RMS，数据不出本机。
为什么报警不立刻触发？
超阈值要持续 800ms 才判定为超标，这是为了过滤瞬时的碰撞声、关门声之类的短促噪音。
报警线附近反复闪怎么办？
5dB 迟滞已经能避免大部分抖动；仍嫌频繁可以把阈值调高一些，或让环境安静一点。
报警时会怎么通知我？
四种方式同时生效：页面红闪、蜂鸣声、机身振动，以及一条桌面通知。
