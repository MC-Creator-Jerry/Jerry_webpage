新闻主页

每日双语全球要闻，覆盖 10 大领域；每天由 Cloudflare Worker 生成后推送到 GitHub Pages。

能做什么

  • 每日双语要闻每天一份中英对照的全球要闻，打开即是今天的内容。
  • 覆盖 10 大领域从时政科技到财经生活，按领域分区浏览。
  • 自动生成与推送Cloudflare Worker 每天生成好内容，再推送到 GitHub Pages，无需手动更新。
  • 中英一键切换中英对照切换，可选择「仅此页」或「所有页」两种作用域并记住你的选择。
  • 朗读支持用语音合成把当天的新闻念出来，通勤时也能听。

怎么登录

新闻主页的公开内容无需登录即可阅读。如果要在其他站点使用需要账号的功能，用小蓝页账户登录即可——身份在各站之间互通。

  • 阅读无需登录所有新闻页面公开可读，打开即用。
  • 需要账号时用小蓝页登录邮箱验证码登录或 GitHub 登录都支持。
  • 身份互通在任一站点登录，其他站点自动识别同一身份。

提示：登录只是为了跨站共用身份，看新闻本身不登录也完全够用。

主要功能速查

  • 双语日报每条要闻都有中英两版。
  • 领域导航10 大领域分区查看。
  • 语言切换中英切换，可选仅此页或所有页。
  • 朗读语音合成朗读当前页面内容。
  • 每日更新Worker 生成后当天自动上线。

常见问题

新闻多久更新一次？
每天一次，由 Cloudflare Worker 生成后推送到 GitHub Pages。
中英切换会影响别的页面吗？
取决于你选的作用域：选「仅此页」就只改当前页；选「所有页」会被记住并在全站生效。
需要注册才能看新闻吗？
不需要，新闻内容公开可读；需要跨站统一身份时才用小蓝页账户登录。
朗读功能怎么用？
用浏览器内置的语音合成朗读当前页面的内容，现代浏览器都支持。
内容和站点是怎么托管的？
每天由 Cloudflare Worker 生成好，再推送到 GitHub Pages，所以它是纯静态页面，加载很快。
