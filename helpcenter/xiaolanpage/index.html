小蓝页

Jerry 的数字花园主站，也是所有产品的统一入口和账号中心。

能做什么

  • 顶栏产品快搜在顶栏输入关键词即可直达任意产品，搜索会匹配名称、快捷键和简介三个字段。
  • 个人资料页在 /personal_profile/ 维护名字、简介、技能和常用链接。
  • 博客与留言板/blog/ 写文章，/guestbook/ 给站点留言。
  • 群组、私信与通知/groups/ 讨论、/messages/ 一对一聊天、/notice/ 收站内通知与评论提醒。
  • 积分榜、订阅与兑换/points/ 看积分榜、/subscribe/ 订阅邮件更新、/redeem/ 兑换权益。
  • 布局编辑点文字直接改、点图片换图，改完保存即对所有访客生效。

怎么登录

所有站点统一走小蓝页单点登录（SSO）：用小蓝页账户登录，身份在各站之间互通。

  • 邮箱验证码登录或注册输入邮箱 → 收验证码 → 设密码，一次搞定。
  • GitHub 登录点 GitHub 图标授权即完成登录，拿到的是同一个站点身份。
  • 身份互通在任意站点登录，其余站点自动识别，无需重复注册。
  • 创作者功能自动开放书栈、茶馆等站点的创作者功能，登录后自动获得相应角色。

提示：每日签到可得调度券 +1，可用于打赏支持站内的创作者。

主要功能速查

  • /personal_profile/名字、简介、技能与链接。
  • /blog/发布与阅读文章。
  • /guestbook/给站点留言。
  • /groups/ · /messages/群组讨论与一对一私信。
  • /notice/ · /points/站内通知与积分榜。
  • /subscribe/ · /redeem/邮件订阅与兑换码。

常见问题

顶栏的搜索是怎么工作的？
搜索走 functions/api/search.js，只匹配产品的 name、keys 和 desc 三个字段，命中即给出直达链接。
忘记密码怎么办？
走邮箱验证码登录或注册入口重新设置即可，不需要旧密码。
GitHub 登录和邮箱登录哪个好？
两者等价，登录后拿到的是同一个站点身份；GitHub 少填一次邮箱，邮箱方式则完全独立于第三方平台。
我改了首页布局，别人也会看到吗？
会。布局编辑保存后即对所有访客生效，属于站点级的公开改动。
积分和调度券有什么区别？
积分来自每日签到，可在 /points/ 的积分榜看到；调度券用于给站内的作品打赏。
