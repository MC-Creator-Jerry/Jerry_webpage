书栈 BookStation

一个独立的小说站：书架、内置阅读器、章节管理；登录就能开书，正文纯文本渲染零 XSS。

能做什么

  • 书架浏览在 bookshelf.html 按分类和热度找书。
  • 内置阅读器在 read.html 直接读，章节连续、不用跳来跳去。
  • 章节管理给作品增删改章节、调整顺序。
  • 创作者中心在 admin/ 管理自己的书。
  • 收藏夹把想读的书收起来，随时回来接着读。
  • 兑换赞助码在 redeem.html 输入赞助码即可兑换相应权益。
  • 纯文本渲染正文一律按纯文本渲染，从根子上杜绝 XSS。

怎么登录

书栈与小蓝页共用一套账户：用小蓝页账户登录，身份在各站之间互通。

  • 用小蓝页账户登录邮箱验证码或 GitHub 登录都行。
  • 登录后普通用户即为创作者登录后自动获得创作者角色，可直接管理自己的书。
  • 管理员自动拥有全站权限小蓝页管理员登录后自动获得书栈全站管理权限。
  • 身份互通在任一站点登录，其余站点自动识别同一身份。

提示：赞助码的兑换入口是 redeem.html；兑换后的权益与账号绑定。

主要功能速查

  • bookshelf.html按分类和热度浏览书库。
  • read.html站内阅读器，连续翻章。
  • admin/管理自己的书与章节。
  • 章节管理增删改章节并排序。
  • 收藏夹收藏想读的书。
  • redeem.html兑换赞助码。

常见问题

我该怎么发布自己的书？
登录后普通用户即为「创作者」，在创作者中心 admin/ 建书，再逐章添加内容即可。
管理员和我有什么不同？
小蓝页管理员登录后自动获得书栈的全站管理权限，普通用户则只能管理自己的书。
阅读器安全吗？
正文一律按纯文本渲染，不解析任何 HTML 或脚本，所以不存在 XSS。
赞助码怎么用？
打开 redeem.html，输入赞助码兑换，权益立即到账并绑定当前账号。
在书栈需要另外注册吗？
不需要，用小蓝页账户登录即可，身份在各站之间互通。
